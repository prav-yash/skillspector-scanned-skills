# Tavily Tool Usage Notes

Use `Tavily` when the user needs current travel information for Europe, such as:

- attraction opening hours
- transport disruption checks
- local event discovery
- current ticket/pass prices
- visa or entry-rule source discovery
- weather or safety-update source discovery

Use Tavily results as starting points and prefer official sources when the topic is high-impact, such as visas, entry rules, transport disruption, or safety notices.

Do not invent current facts if Tavily is not used or if the result does not support the answer.
