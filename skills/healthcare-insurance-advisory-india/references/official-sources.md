# Official Sources — Verify Here Before Citing Specifics

*Purpose: when a user's situation needs exact, current wording — a clause number, a monetary threshold, an office contact — fetch/verify from these primary sources rather than relying on memory or the summaries in this skill's other reference files. Cite the document by its official name so the user can quote it to their insurer.*

## Regulator (IRDAI)

- **Master Circular on Health Insurance Business** — Ref: **IRDAI/HLT/CIR/MISC/77/05/2024**, dated 29 May 2024. The single consolidated rulebook for health insurance policyholder entitlements (repealed 55 earlier circulars; reviewed annually — check for a newer version before quoting). Published on **irdai.gov.in** under Circulars/Health. Key contents: cashless authorization TATs (1 hour pre-auth / 3 hours discharge), 60-month moratorium on non-disclosure denials, 36-month cap on PED waiting periods, 30-day free-look, portability rules.
- **Master Circular on Protection of Policyholders' Interests (2024)** — policyholder rights, grievance-handling obligations, and service TATs across the policy lifecycle. Also on irdai.gov.in.
- **IRDAI main site:** https://irdai.gov.in — for any newer circular; the Master Circular is reviewed every year, so search the site for the latest version before quoting clause numbers.

## Grievance & Ombudsman

- **Bima Bharosa (IGMS)** — IRDAI's integrated grievance portal for complaints against insurers: https://bimabharosa.irdai.gov.in
- **Council for Insurance Ombudsmen (CIO)** — official Ombudsman information: current monetary jurisdiction limit, list of Ombudsman offices by territory, online complaint filing: https://www.cioins.co.in — always look up the user's correct office here by their location; never state an office address or the monetary threshold from memory.

## Insurer-specific (per user's case)

- The user's own insurer's website → "Grievance Redressal" page for the GRO's contact, and "Claims" page for the exact document checklist and claim-intimation process. Every IRDAI-licensed insurer must publish these.
- The user's **policy schedule / Certificate of Insurance** — the ultimate authority on their coverage, sub-limits, waiting periods, and exclusions. No external source substitutes for it.

## Adjacent (out of this skill's core scope, but commonly asked)

- **National Health Authority / Ayushman Bharat PM-JAY:** https://nha.gov.in and https://beneficiary.nha.gov.in (eligibility check). Government scheme, separate system from private insurance — point users here rather than answering scheme specifics from memory.

## Usage rules

1. Prefer fetching the current page over quoting this file — this file lists *where* truth lives, not the truth itself.
2. When citing a rule to a user in a dispute, give them the document's official name and reference number (e.g., "Master Circular on Health Insurance Business, IRDAI/HLT/CIR/MISC/77/05/2024") — insurers respond to precise citations.
3. If a fetched page contradicts this skill's summary files, the fetched official source wins; mention the discrepancy to the user.
