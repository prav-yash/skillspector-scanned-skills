# Custom PC Build Expert Reference

## Build Categories

| Build Type | Typical Priority |
|---|---|
| Budget gaming | GPU value, balanced CPU, 16 GB RAM, reliable PSU |
| 1080p gaming | GPU + CPU balance, 16–32 GB RAM |
| 1440p gaming | stronger GPU, 32 GB RAM recommended |
| 4K gaming | high-end GPU first, strong PSU, good airflow |
| Office PC | stable CPU, SSD, 16 GB RAM, low noise |
| Creator PC | CPU cores, RAM, GPU acceleration, fast storage |
| AI/ML workstation | GPU VRAM, CUDA support, RAM, cooling, PSU |
| Streaming PC | CPU/GPU encoder, RAM, storage, quiet cooling |
| Small form factor | compatibility, thermals, PSU form factor |

## Component Compatibility Checklist

Before final recommendation, check:

- CPU socket matches motherboard.
- Motherboard chipset supports CPU.
- BIOS support is confirmed for chosen CPU.
- RAM type matches motherboard: DDR4 vs DDR5.
- RAM speed is reasonable for platform.
- GPU fits inside the case.
- CPU cooler fits inside the case.
- PSU wattage and connectors are sufficient.
- Case supports motherboard size.
- Storage slots are enough.
- Cooling/airflow is adequate.
- Monitor resolution matches GPU class.

### Gaming

| Target | General Direction |
|---|---|
| 1080p budget | value GPU + midrange CPU |

| Workload | General Direction |
|---|---|

## Brand Guidance

Do not blindly recommend a brand only by name.

Compare based on:

- warranty
- local service
- model-specific quality
- thermals
- VRM/cooling design
- reviews
- price
- availability

Examples of common component brand categories:

| Component | Common Brands to Compare |
|---|---|
| CPU | AMD, Intel |
| GPU Chip | NVIDIA, AMD, Intel |
| GPU Board Partners | ASUS, MSI, Gigabyte, Zotac, Sapphire, PowerColor, Galax, Inno3D |
| Motherboard | ASUS, MSI, Gigabyte, ASRock |
| RAM | Corsair, G.Skill, Kingston, Crucial, TeamGroup, ADATA |
| SSD | Samsung, WD, Crucial, Kingston, Seagate, Solidigm |
| PSU | Corsair, Seasonic, Cooler Master, DeepCool, MSI, Antec, Thermaltake |
| Case | Corsair, Cooler Master, DeepCool, NZXT, Lian Li, Fractal, Ant Esports |
| Cooler | Noctua, DeepCool, Cooler Master, Corsair, Arctic, Thermalright |

Brand names alone do not prove quality. Recommend checking the exact model.

## Budget Allocation Heuristics

For gaming builds:

- GPU often takes the largest share.
- Avoid overspending on motherboard if it reduces GPU budget.
- Do not compromise too much on PSU.
- Case airflow matters more than only looks.
- 32 GB RAM is increasingly useful for mid/high builds.

For workstation builds:

- Allocate based on software.
- Some workloads need CPU cores.
- Some workloads need GPU acceleration.
- Some need RAM and storage more than GPU.
- Ask software names before finalizing.

## Questions to Ask the User

Ask only what is necessary:

1. What is your budget and currency?
2. What country/city are you buying in?
3. What is the main use: gaming, editing, coding, AI, office?
4. Do you need monitor/keyboard/mouse/UPS included?
5. What resolution and FPS target?
6. Any preferred brands?
7. Any existing parts to reuse?
8. Do you care about RGB, silence, or small size?
9. Do you need Wi-Fi/Bluetooth?
10. When are you planning to buy?

## Final Recommendation Checklist

Before final answer, include:

- Build table
- Estimated total
- Compatibility notes
- Upgrade path
- Risks/verification points
- Alternatives if budget changes
