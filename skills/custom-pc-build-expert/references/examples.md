# Custom PC Build Expert Examples

## Example: Gaming PC Recommendation

User:
"I want a gaming PC under ₹80,000 for 1080p gaming."

Response structure:

| Component | Recommendation | Why |
|---|---|---|
| CPU | midrange gaming CPU | enough for 1080p |
| GPU | best value GPU within budget | main gaming performance driver |
| Motherboard | compatible board with upgrade path | socket/chipset support |
| RAM | 16–32 GB | based on budget |
| Storage | 1 TB NVMe SSD | games and OS |
| PSU | quality 550–650W unit | safe headroom |
| Case | airflow-focused case | cooling stability |

Then add:
- estimated cost
- current price check needed
- upgrade path
- final verification before buying

## Example: Uploaded Quote Review

User uploads a quotation.

Response structure:

| Part | In Quote | Keep / Change | Reason |
|---|---|---|---|

Mention:
- overpriced parts
- weak PSU risks
- motherboard mismatch
- missing SSD/RAM details
- brand/model uncertainty

Do not invent missing quote details.
